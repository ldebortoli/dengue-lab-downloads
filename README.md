# Dengue Lab downloads

Official portable releases of Dengue Lab by Licenciado Dengue and Smegmo Company 3 - Turbodengue Intergaláctico Recargado LLC.

Download and installation guide: https://licenciadodengue.com/lab/

Dengue Lab creates local sample-based VST3 instruments. Import WAV, AIFF, FLAC, OGG, MP3 or ZIP/RAR, or check individual audio files in a folder. Choose supplied artwork or add a PNG/JPEG cover, then set volume, pitch and a MIDI root or trigger note for each sample. Use chromatic keyboard mode or exact-note drum mode in your DAW. Audio stays on your computer; no accounts, AI services or audio uploads. The local lexical name filter can miss abuse or reject legitimate names.

Download complete portable archives from Releases and extract the entire folder before launching. Keep each generated VST3 folder intact, including Resources, source and licences. A generated instrument targets the operating system on which it was created. Pitch changes playback speed and duration. Keep your originals and generated instrument; the builder session itself is not saved.

Each release includes SHA256SUMS.txt. Each portable includes the complete corresponding engine/application source, pinned JUCE source and third-party notices. The standalone engine-source archive is also available as a release asset. The application and engine are AGPL-3.0; third-party licences and original credits remain in the packages. This repository contains only public distribution documentation, not the private development history.

Assisted translations cover the same 176 options as the official website. They are not native-language certified. See each release for platform-specific validation and signing limitations.
